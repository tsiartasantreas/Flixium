# IPTVication — Preliminary Plan (v3)

## 1. Vision & Scope
A **Netflix-clone IPTV player** for Android phone / Android TV / Fire TV, sideloaded via the **Downloader app** from GitHub Releases. Supports M3U playlists: VOD (movies/series), Live TV + EPG, Catch-up TV, Radio, favorites. **Four user classes.** Free + Pro ($8.99 once-off lifetime, email-keyed, 5 devices). Includes a **developer Admin Panel** for you to manage users and subscriptions.

> 🎯 **#1 HARD REQUIREMENT — Netflix fidelity:** Near pixel-for-pixel replica of Netflix on phone + TV. The ONLY permitted visual deviation is a **slight color palette shift** (background stays near-black; Netflix red → slightly different accent). Layout, type hierarchy, spacing, card geometry, focus states, animations, hero billboards, scroll rows, mobile bottom nav, TV left-rail nav, detail sheets, episode lists — all mirror Netflix. Per-screen acceptance gate: side-by-side with Netflix reference, ship only when near-indistinguishable. **Legal:** clone UX/layout only — no Netflix wordmark/logo/art; accent shift signals differentiation. Brand name TBD in spec.

**Non-goals v1:** iOS, recommendation engine, transcoding, parental PINs, Apple TV/Roku.

## 2. The Four User Classes
| Class | Auth | Can do |
|---|---|---|
| **Anonymous** | None | 1 playlist, local-only, no sync/Continue/multi-user |
| **Registered — Free** | Email (Supabase Auth) | All anon + account identity, cloud favorites backup, upgradeable |
| **Registered — Pro** | Email + license | All Free + multi-playlist, multi-profile, Continue/Up Next, sync (5 devices) |
| **Admin (you)** | Email + admin flag | All Pro + **Admin Panel**: users, subscriptions, devices, revenue, flags, audit log |

Upgrade: anonymous → free → pro (Revolut $8.99). Admin flag set manually in Supabase for your email.

## 3. Final Stack
| Layer | Choice |
|---|---|
| App | **Flutter** (phone+TV+Fire TV, TV-aware day 1, one APK) |
| Player/Audio | **`media_kit`** (libmpv) — HLS/DASH/awkward containers + Radio |
| On-device DB | **Drift** (SQLite) |
| M3U/EPG | `dart_m3u_filter` + custom XMLTV parser |
| UI kit | Custom Netflix-clone design system + `flutter_animate` (NOT generic Material) |
| **DB+Auth+schema web UI** | **Supabase Cloud (project "IPTVication")** from day 1 — Postgres + Auth + Storage + **Supabase Studio web UI** (your schema editor, in-cloud). Single source of truth. **No local Docker** (per your call). |
| **Edge compute** | **Wasmer Edge free tier** — ONE app co-hosts the Admin Panel SPA + Payment/Licensing API |
| Admin UI | **Next.js static export** (React, Wasmer React Static Site guide) |
| Payments | **Revolut Merchant API** (Order + signed webhook) |
| Distribution | **GitHub Releases + Downloader shortcode** |

### 4.2 Component responsibilities
1. **Flutter app** — UI (Netflix clone), playback, local persistence, M3U/EPG parsing. Reads entitlement from Supabase (auth + license row). Calls Wasmer only for checkout + periodic device verify.
2. **Supabase "IPTVication"** — single source of truth. Tables, Auth, Storage, RLS, Studio web UI. Zero local Docker.
3. **Wasmer Edge app** — one deploy hosting (a) Admin SPA and (b) payment+licensing API. Holds service-role key + Revolut key + webhook secret (server-side only, never shipped to app).
4. **Revolut Merchant API** — Order, hosted checkout, signed webhook.

### 4.3 Key data flows
**Activation (anon → Pro):** App→`/checkout`{email,fp}→Wasmer→Revolut Order→returns URL→user pays→Revolut webhook→Wasmer verifies sig→idempotent upsert license+register device(<5)→app polls `/verify-device`→entitlement=pro.
**Admin manages user:** Admin login (Supabase Auth, is_admin check)→Panel→Wasmer `/admin/*`(service-role)→Supabase updates→next app launch by user re-verifies→downgrade applied.
**Continue Watching (Pro, cross-device):** play writes `watch_progress` to Drift + Supabase sync table; other device pulls it.

### 4.4 Security boundaries
- App holds only anon key + JWT; RLS enforces own-rows-only; NEVER service-role.
- Wasmer functions hold service-role + Revolut key + webhook secret.
- Admin Panel auths via Supabase Auth; every admin call re-checks `is_admin` on JWT; no client-side service-role.
- Webhook sig verified; idempotency key prevents double-mint.

## 5. Netflix Design System (summary; full in spec)
- **Color:** bg `#141414`, surfaces `#181818`/`#221` (identical); accent Netflix red `#E50914`→`#E11D48` (proposed, slight shift, same role).
- **Type:** bold condensed billboards (free equiv of Netflix Sans — Bebas/Anton/Archivo Narrow, finalized in spec); neutral grotesk body (Inter/Roboto Flex).
- **Mobile:** sticky top bar (opaque on scroll), bottom tabs (Home, Series, Movies, Live, Radio, My List), full-bleed hero, focus chevron rows.
- **TV (10-foot):** left vertical nav rail, giant hero, D-pad rows with scale+glow focus card, detail modal slides up.
- **Cards:** poster 2:3 (VOD), 16:9 (Live/Radio), ~4px radius, focus lift 1.08 + shadow + accent ring.
- **Motion:** focus 200ms ease-out, neighbor dim, hero crossfade, sheet slide (`flutter_animate`).
- **Phase 0 reference capture:** screenshot/annotate real Netflix per screen → `docs/ui-references/` → visual acceptance criteria.

## 7. Data Model (full schema in spec, via Supabase Studio)
**On-device (Drift):** playlists, channels/vod/series/episodes, epg_programmes (TTL), favorites, watch_progress(Pro), user_profiles(Pro).
**Supabase Postgres (RLS):**
- `profiles`(id↔auth.uid, email, display_name, is_admin, tier[anonymous|free|pro], created_at)
- `licenses`(id, email, status[active|revoked|pending], source[revolut|manual], amount, timestamps)
- `devices`(id, license_id, fingerprint, name, platform, last_seen, revoked)
- `activation_codes`(code, email, device_fp, status, expires_at)
- `watch_progress_sync`(user_id, content_id, position, duration, updated_at)
- `favorites_sync`(user_id, content_id, playlist_id, added_at)
- `feature_flags`(key, value, audience) — admin-controlled
- `admin_audit_log`(admin_id, action, target, ts)

## 11. Wasmer Edge `app.yaml` (prepared — autodeploy)
File: `/edge/app.yaml`. Schema confirmed from official Wasmer Edge docs (`kind: wasmer.io/App.v0`).
```yaml
kind: wasmer.io/App.v0
owner: <YOUR_WASMER_USERNAME>   # set during install (§12)
name: iptvication-edge
package: '.'                    # uses wasmer.toml in same dir
debug: false
# Secrets set via CLI (never committed):
#   wasmer app secret set SUPABASE_URL=... --app iptvication-edge
#   wasmer app secret set SUPABASE_SERVICE_ROLE_KEY=... --app iptvication-edge
#   wasmer app secret set REVOLUT_API_KEY=... --app iptvication-edge
#   wasmer app secret set REVOLUT_WEBHOOK_SECRET=... --app iptvication-edge
#   wasmer app secret set ADMIN_SESSION_SECRET=... --app iptvication-edge
env:
  SUPABASE_URL: "${SUPABASE_URL}"
  SUPABASE_SERVICE_ROLE_KEY: "${SUPABASE_SERVICE_ROLE_KEY}"
  REVOLUT_API_KEY: "${REVOLUT_API_KEY}"
  REVOLUT_WEBHOOK_SECRET: "${REVOLUT_WEBHOOK_SECRET}"
  ADMIN_SESSION_SECRET: "${ADMIN_SESSION_SECRET}"
capabilities:
  instaboot:                    # fast cold starts on checkout/verify
    requests:
      - path: /api/checkout
      - path: /api/verify-device
      - path: /_bootstrap
  cdn_cache:
    enabled: true               # cache admin static assets at edge
```
Companion `wasmer.toml` (in `/edge`) declares the package; React static-site bundler builds the Admin SPA; API runs as edge handlers. Git push → autodeploy (Wasmer for GitHub). ⚠️ [wasmer#6803](https://github.com/wasmerio/wasmer/issues/6803): `wasmer deploy` can corrupt `app.yaml` — keep in git, re-push if mangled.
